## Exchanging links

Submit a PR directly—just update `src/_data/friends.json`.

```json
{
  "siteTitle": "XnneHang",
  "siteUrl": "https://xnnehang.top",
  "siteDesc": "写代码是因为爱。",
  "siteDescEn": "I code because I love it.",
  "siteIcon": "https://xnnehang.top/avatar.jpg"
}
```

## Link-exchange guidelines

- Friendship comes before the link.
- The site must use HTTPS.
